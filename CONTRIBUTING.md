# Contributing

This repo holds the setup instructions for Paddle's hosted MCP server. The server's source code isn't public, so we don't accept pull requests here.

If you've spotted a problem with these instructions or the MCP server, or have a feature request, please [open an issue](https://github.com/PaddleHQ/paddle-remote-mcp-instructions/issues).

For help with the Paddle API or building your integration, contact our support team at [sellers@paddle.com](mailto:sellers@paddle.com).

To report a security vulnerability, see [SECURITY.md](SECURITY.md).
